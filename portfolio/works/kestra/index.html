PROJECT OVERVIEW

プロジェクト概要

CLIENT
KESTRA HAIR
CATEGORY
Hair Salon / Website
ROLE
Planning / Information Design / Web Design / Development / Responsive Design / WordPress / SEO
YEAR
2026

岐阜市の実店舗美容室「KESTRA HAIR」のWebサイトを制作。既存の予約サイトだけでは伝えきれない、サロンの落ち着いた雰囲気やスタッフへの安心感、技術力を伝えることを目的に、企画・情報設計からデザイン、実装まで一連の制作を行いました。

PROCESS

制作の考え方

  1. 01

    CHALLENGE

    課題

    予約サイトでは価格やメニューが中心となり、サロンの雰囲気やスタッフへの安心感、KESTRAらしさまで十分に伝えることが難しい。

  2. 02

    TARGET

    30〜50代の女性

    価格やトレンドだけでなく、髪の悩みに寄り添う技術や落ち着いた時間を求める層へ、サロンの価値をきちんと伝える必要があった。

  3. 03

    APPROACH

    アプローチ

    予約サイトを「予約する場所」、Webサイトを「予約する前に安心してもらう場所」と役割分担。来店前に知りたい情報を整理しました。

DESIGN CONCEPT

デザインコンセプト

余白と写真で、
サロンの静かな空気感を伝えるデザイン。

ベージュを基調に、やわらかく落ち着いたトーンで統一。

Quiet / Refined / Warm / Trust
